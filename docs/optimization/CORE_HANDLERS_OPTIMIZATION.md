# 核心命令处理模块优化任务

## 模块概述

核心命令处理模块是GitAI的入口点，负责处理所有CLI命令的执行。当前状态：大部分handler只有占位符实现，需要实现完整的业务逻辑。

## 当前问题分析

### 现有实现状态
- **Review Handler**: 仅有占位符，打印参数信息
- **Commit Handler**: 基础框架存在，核心逻辑未实现
- **Scan Handler**: 基础参数解析，OpenGrep集成缺失
- **其他Handlers**: 大部分为空实现或简单占位符

### 关键问题
1. 缺少多维度数据融合逻辑
2. AI服务集成不完整
3. 错误处理机制不统一
4. 输出格式支持有限
5. 性能优化和缓存机制缺失

## 优化任务清单

### 1. Review Handler 完整实现

**优先级**: 🔴 高
**预估工期**: 5-7天

#### 1.1 核心分析逻辑
- [ ] **任务**: 实现Git diff获取和预处理
  **文件**: `crates/gitai-cli/src/handlers/review.rs`
  **描述**: 集成git diff获取，支持多种比较基准（HEAD, commit hash, branch）
  **验收标准**: 能够正确获取staged和unstaged changes，支持大型项目

- [ ] **任务**: 多维度数据采集框架
  **文件**: `crates/gitai-cli/src/handlers/review.rs`
  **描述**: 并行采集Tree-sitter分析、安全扫描、DevOps上下文数据
  **验收标准**: 各维度数据独立采集，失败不影响其他维度

- [ ] **任务**: AI提示词构建引擎
  **文件**: `crates/gitai-cli/src/handlers/review.rs`
  **描述**: 基于多维度数据构建上下文丰富的AI提示词
  **验收标准**: 生成的提示词包含代码变更、结构分析、安全问题、任务上下文

#### 1.2 缓存机制实现
- [ ] **任务**: 智能缓存键生成
  **文件**: `crates/gitai-cli/src/handlers/review.rs`
  **描述**: 基于diff内容、分析选项、语言等生成MD5缓存键
  **验收标准**: 相同输入产生相同缓存键，不同输入产生不同键

- [ ] **任务**: 缓存读写逻辑
  **文件**: `crates/gitai-cli/src/handlers/review.rs`
  **描述**: 实现缓存的读取、写入、失效管理
  **验收标准**: 命中缓存时直接返回结果，未命中时执行分析并保存缓存

#### 1.3 输出格式支持
- [ ] **任务**: 多格式输出支持
  **文件**: `crates/gitai-cli/src/handlers/review.rs`
  **描述**: 支持text、json、html三种输出格式
  **验收标准**:
  - text: 人类友好的终端输出
  - json: 结构化数据，便于工具集成
  - html: 可视化报告，包含图表和高亮

## 风险评估

### 高风险项
1. **AI服务集成稳定性**: 依赖外部AI服务，可能存在不稳定
2. **大项目性能**: 处理大型代码仓库时的性能问题

### 缓解策略
1. **重试机制**: 实现AI服务的重试和降级
2. **增量分析**: 实现增量分析，避免全量扫描
3. **缓存优化**: 通过智能缓存减少重复计算
